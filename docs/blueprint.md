# **App Name**: BioMyDream Academy

## Core Features:

- Course Listings: Display a list of available courses with details like subject, level (CBSE, ICSE, WBBSE, WBCHSE), and tutor information.
- Tutor Profile: Showcase the tutor's qualifications (B.Sc., M.Sc., B.Ed., D.El.Ed.), experience, and teaching fields.
- Contact Form: Enable students to contact the tutor via a contact form to ask questions about courses.
- Online Classes: Allow tutor to host live online classes for registered students.
- Study Material Access: Allow students to access free study materials.
- Mock Test System: Admin panel and Student profile page for the system that provides the possibility of weekly online mock test to test learning progress.

## Style Guidelines:

- Primary color: Emerald green (#3CB371) inspired by the science, knowledge, and life to connect with the subject matter and logo.
- Background color: Very light green (#F0FAF4), a desaturated shade of the primary, for a soft and clean backdrop.
- Accent color: Teal (#008080), an analogous color to green, for highlights and interactive elements.
- Headline font: 'Belleza' sans-serif for headings and titles, providing a stylish and artistic look.
- Body font: 'Alegreya' serif font for body text to enhance readability and a intellectual feel, due to body being present more than headings and Belleza will be good to show art.
- Use clear, science-themed icons (e.g., molecules, books, brains) to represent course categories and features.
- Maintain a clean, organized layout with clear sections for course listings, tutor profiles, and contact information.
